# 🎤 Projeto Gonzaguinha - O que é, o que é?

> "Viver e não ter a vergonha de ser feliz..."

Este é um projeto de site biográfico e lírico focado na obra-prima de **Gonzaguinha**. O objetivo é celebrar a música brasileira utilizando tecnologias modernas de desenvolvimento web front-end.

## 🚀 Sobre o Projeto
O site foi construído do zero para ser uma página única (*Single Page Application* visual), destacando a história da música "O que é, o que é?", curiosidades sobre o álbum de 1982 e a letra completa para os entusiastas da MPB.

## 🛠️ Tecnologias Utilizadas
O projeto utiliza o "trio de ferro" do desenvolvimento web moderno:

* **HTML5**: Estruturação semântica do conteúdo.
* **CSS3**: Estilização personalizada (gradientes, tipografia e efeitos de overlay).
* **Bootstrap 5.3**: Framework utilizado para:
    * **Grid System**: Layout responsivo (se adapta a celulares e tablets).
    * **Componentes**: Navbar fixa, Cards e Botões.
    * **Utilidades**: Espaçamentos (margens/paddings) e tipografia.
* **Bootstrap Icons**: Ícones vetoriais para navegação e detalhes.

## 📱 Funcionalidades
- [x] **Design Responsivo**: O layout se ajusta automaticamente a qualquer tamanho de tela.
- [x] **Menu de Navegação Inteligente**: Links internos que levam o usuário direto para a História ou para a Letra.
- [x] **Player de Vídeo**: Incorporação do YouTube com proporção mantida (16:9).
- [x] **Interface Intuitiva**: Foco total na leitura e na experiência do usuário.
